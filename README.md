Global Wind Map is an interactive, client-side web application that visualizes real-time global wind speed and direction using a dynamic map interface and live meteorological data sources. 
It is a static web application that is built using HTML, CSS and JavaScript.
It uses the Leaflet mapping library and OpenStreetMap tiles to display wind conditions for major cities around the world.
The application implements a dual-API strategy: OpenWeatherMap is used as the primary data source, with Open-Meteo serving as an automatic fallback if the primary API is unavailable or rate-limited.
The project is fully client-side and deployed using GitHub Pages.
Data Sources:
OpenWeatherMap (Primary): https://openweathermap.org/
Open-Meteo (Backup): https://open-meteo.com/
The application is hosted via github pages: https://arnaaaaa.github.io/global_wind_map/
